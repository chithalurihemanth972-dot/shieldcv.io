</div>

<br>

All commands run through `run.py`. Add `--help` to any.

```bash
python run.py scan    demo/data/poisoned          # 📊  scan a dataset

python run.py report  --help                      # 📋  signed report
```

Options: `--json [PATH]` for machine output, `--limit N` to cap images.


## ⚙️ ━━━━━━━━━ HOW IT WORKS ━━━━━━━━━ ⚙️

</div>

<br>

<details>
<summary><b>📊 &nbsp;Data Integrity — src/scanners/data_scanner.py</b></summary>

<br>

**Three independent detection methods — TWO must agree for HIGH confidence:**

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   📡  FFT High/Low Frequency Ratio                          │
│   📊  16x16 Block-Variance Z-Scores                         │
│   📈  SVD Spectral Signatures                               │
│                                                             │
│   Single method -> capped at 0.45 (below HIGH cutoff)       │
│   Two+ methods  -> HIGH confidence finding                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**Also detects:**
- 🔄 Label flipping (class-centroid distance + KNN)
- 📋 Near-duplicate flooding (pHash + SSIM)
- 📊 Out-of-distribution (Mahalanobis + energy score)

**Risk formula:** `0.4*trigger + 0.3*flip + 0.2*dup + 0.1*ood`

</details>

<details>
<summary><b>🧠 &nbsp;Model Integrity — src/scanners/model_auditor.py</b></summary>

<br>

**Auto-detects access level and degrades gracefully:**

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   🟢  WHITE-BOX  ->  Full weight inspection                  │
│   🟡  GREY-BOX   ->  Limited inspection                      │
│   🔴  BLACK-BOX  ->  Behavioural fingerprinting              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**Methods:**
- 🔐 SHA-256 weight fingerprinting
- 📊 Per-layer statistics
- 🧠 Neural Cleanse trigger reconstruction
- 📈 Activation clustering
- 🔍 Black-box behavioural fingerprinting

> ❌ **NO retraining ever occurs**

</details>

<details>
<summary><b>🔗 &nbsp;Inference Provenance — src/scanners/crypto_chain.py</b></summary>

<br>

**Ed25519-signed, hash-chained records in tamper-evident SQLite:**

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   ⚠️  HASH_MISMATCH                                         │
│   🔗  BROKEN_LINK                                           │
│   📊  SEQUENCE_GAP                                          │
│   🔁  DUPLICATE_NONCE                                       │
│   ⏰  TIMESTAMP_REGRESSION                                  │
│   ❌  MISSING_GENESIS                                       │
│   🔄  PAYLOAD_MISMATCH  <- re-derives output digest         │
│       (attacker who edits data + recomputes hash            │
│        is STILL caught)                                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

</details>

<details>
<summary><b>📈 &nbsp;Drift Detection — src/scanners/drift_detector.py</b></summary>

<br>

**Distinguishes natural drift from attacks:**

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   🌿  NATURAL OPERATIONAL DRIFT                             │
│       -> Dusk, monsoon, sensor ageing                       │
│       -> NOT escalated as attacks                           │
│                                                             │
│   ⚠️  SUSPICIOUS MANIPULATION                               │
│       -> Deliberate data/model tampering                    │
│       -> Escalated for review                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

</details>

White-box model audit peaks near **0.9 GB**. On machines with under 3 GB free, `run_demo.py` automatically runs each stage in a separate process. Force this with `--isolate`.

| Limitation | Impact |

| Neural Cleanse | Requires white-box access |
